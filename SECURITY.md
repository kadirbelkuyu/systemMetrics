# Security Policy

## Supported Versions

We release patches for security vulnerabilities. Which versions are eligible for patches depends on the vulnerability. 

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it to us via [GitHub Issues](https://github.com/kadirbelkuyu/systemMetrics/issues).

Please include as much information as possible to help us understand and resolve the issue quickly.
